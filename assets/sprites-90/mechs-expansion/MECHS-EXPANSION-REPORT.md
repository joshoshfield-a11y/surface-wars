## Name collisions (documented, not overwritten)

- `expansion_warden` is used because `warden` already exists in `sprites-90/mechs/`. The original warden was untouched.
- `expansion_colossus` is used because `colossus_engine` already exists in `sprites-90/units/`. The original colossus_engine was untouched.
- `rampart_mk2`, `longshot`-class chassis, and the vespid-class chassis are new slugs distinct from the existing `rampart`, `longshot`, and `vespid` in the main set; none of those were overwritten.

## Rejected / regenerated

- Bulwark, Vespid, Striker: NONE — first-pass grids passed (strict top-down, barrels straight up, no bleed, no text).
- Longshot: no chassis rejected; one pipeline fix — faint grey grid-divider fragments on the first blue sheet were re-sliced with a 24px inset and re-keyed; flawed first-pass slices preserved in `longshot/raw-flawed/`.
- Additional Part A: NONE — all four grids passed; spider legs radiate diagonally in plan view by design (legs, not barrels) and were not treated as a violation.
- Additional Part B: Bastille blue + red regenerated as single sprites (original corner turret barrels were diagonal ~45°); Chronomancer blue regenerated tick-marks-only (original clock face carried numerals/text). Originals preserved in `additional/raw-flawed-b/`. Nothing diagonal was shipped.

## Honest gaps

- Red silhouettes share class language, not exact outlines, vs blue (separate generation, by design — this is what keeps reds visibly distinct). Notable divergences: red Rampart-class divergences aside, dronewright-red pods float detached, signal_ghost is round in blue but elongated-oval in red, hellhound-red is rounder than blue, red flicker is rounder than blue's dart.
- Weakest team signal: mimic-red (+2 mean R−B, red rim trim + sensor dot only, no large disc) — still labelled red on sheets, but the weakest red in the set.
- Relative size is not preserved across classes in `-512` files (all are 512×512); in-game scaling must come from game data, as with the main set.
- Thin/light chassis will read faint at small sizes by design: threadrunner (~46–56 px opaque width full-size), wraithrunner's faint halo after keying.
- Small flagged artefacts, not hidden: dreadnought-red twin dark centre details blue lacks; thunderhead-red small vertical tick below hull; mortarjack-red tiny grey sliver below hull; stormcaller lightning arcs are FX, not barrels.
- Single stills only: no animation, damage, or wreck frames; no Salvage Clans/Directorate skins beyond blue/red; no real-browser/phone playtest — QC is sheet/grid visual inspection plus alpha/dimension checks.
